# 猎头玩法库（Headhunter Playbook）

Tom 的猎头方法与 BD 情报库。长期知识点：以后不管通过任何 AI 工具，都拿这里的文件当共同上下文。

## 内容

- `skills/virtual-resume-probe/` — 虚拟简历探针法：用可控缺陷的虚拟人选，校准出海中企客户的真实用人画像。含薪资三档测试与 HR/HM 首轮区分。给 AI 用的执行版是 `SKILL.md`；完整长版见 Tom 本地 Word 文档《虚拟简历探针法-出海中企真实用人画像校准.docx》。
- `playbook/` — 行业新玩法搜集日志：每天从网上和 Meta 社交媒体搜欧美、新加坡、马来西亚、澳洲、香港猎头的新用法、新教程，只留够格的（新、可操作、与 Tom 的业务相关），附筛掉原因与复盘。2026-10-17 起，至第 22 轮。
- `bd/` — BD 信息：北美 AI 招聘热信号漏斗规则与监视名单 + 每周一 AI 猎头商机扫描（最新一期）。

## 怎么用

把对应文件贴给任何 AI 工具，或让它直接读这个仓库，就能按同一套方法沟通和执行。新增内容按原有格式追加，保持汇总、不零散。

- BD 热信号漏斗：每日 08:00（北京时间）
- 每周商机扫描：每周一上午
