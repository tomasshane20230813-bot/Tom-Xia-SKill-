# Public Recruiting Knowledge Pack | 招聘知识公开稿

**Status / 状态: Review draft — not uploaded or published. / 待审稿——尚未上传或发布。**

This package is a compact, bilingual, plain-Markdown draft for public reuse by people and AI systems that can read the repository. It distills the user's two authored skills, explicitly saved recruitment-team preferences, and general hiring lessons from a project summary. It is not a dump of every skill or instruction available in the assistant environment.

本包是面向可读取该仓库的人和 AI 的精简双语 Markdown 草稿，整理了用户自建的两项技能、明确保存的招聘团队偏好，以及从项目汇总中抽象出的通用招聘经验。它不是对助手环境中所有技能或指令的导出。

The public repository already contains `skills/virtual-resume-probe/` and `skills/github-playbook-sync/`. Those existing files are not duplicated or modified by this review package.

该公开仓库原本已包含 `skills/virtual-resume-probe/` 与 `skills/github-playbook-sync/`；本次待审包没有重复添加或改动这些既有文件。

## Deliberately omitted / 已有意省略

- Personal phone numbers, email addresses, credentials, tokens, account identifiers, and Agent IDs. / 个人电话号码、邮箱、凭证、令牌、账号标识和 Agent ID。
- Candidate names, candidate-specific cases, resumes, contact details, and personal data. / 候选人姓名、个案、简历、联系方式及个人数据。
- Client-, project-, or job-specific confidential facts, including company names, role details, compensation, and project status. / 客户、项目或岗位专属保密信息，包括公司名称、岗位细节、薪酬和项目状态。
- Private information about where the user's work files are mirrored or backed up. / 用户工作文件同步或备份位置等私人信息。
- Internal system/platform prompts, tool instructions, non-user-authored skills, and operational secrets. / 系统或平台内部提示、工具指令、非用户自建技能及操作机密。
- One-off exceptions tied to a named candidate, dated call, or named opportunity. / 与具体候选人、特定日期通话或特定岗位绑定的一次性例外。
