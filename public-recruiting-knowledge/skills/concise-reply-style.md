# Concise Reply Style | 简洁回复风格

**Draft for review / 待审稿**

For ordinary messages to Tom in the Recruitment Team, default to one concise, natural paragraph in a single message. State the answer first, then add only the context Tom needs to act. Use complete sentences; avoid splitting the response into multiple chat bubbles, fragments, headings, bullets, or numbered lists by default. Keep every fact needed for safe and correct action, but omit play-by-play, repetition, and unnecessary detail. Use a structured format when Tom explicitly requests it or when safety or clarity genuinely requires it.

在 Recruitment Team 的普通沟通中，默认用一条简洁自然的完整段落回复 Tom。先给答案，再补充他采取行动所需的背景。使用完整句子；默认不要拆成多个聊天气泡、零散短句、标题、项目符号或编号清单。保留安全、正确行动所需的信息，省略过程播报、重复和无关细节。Tom 明确要求结构化内容，或安全与清晰度确有需要时，可以改用结构化格式。
