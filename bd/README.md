# BD 信息：北美 AI 招聘热信号与每周商机扫描

Tom 的 BD 情报汇总（每周更新一次最新扫描；漏斗每天 08:00 跑）。

## 每日热信号漏斗

每天 08:00（北京时间）监视 16 家北美 AI/机器人公司的公开招聘板（Greenhouse/Lever/Ashby 公开接口），按 Tom 的规则找 BD 信号。

信号规则：

- P1：挂 45 天以上，或重发，或底薪上限 ≥ 20 万美金
- P2：挂 35–44 天
- 幽灵岗：挂 60 天以上
- 只算 AI/技术/工程岗；招聘类岗位也算（Head of Talent 本身就是 BD 信号）
- 简报只列今日新增 / 新升级的信号；统计行给累计数

关键做法（实测后定）：

- 挂岗天数只用 first_seen 累计，不用 ATS 的发布日期（发布日期不可靠，公司会复用常驻 requisition）。
- 公司统一定薪不触发薪资 P1（Tenstorrent 全公司贴同一个 $100K–$500K 薪段，不是岗位真实薪资）。
- Tesla Optimus 未纳入：自有 ATS，tesla.com 对自动化访问返回 403，无公开 API 可验证。

最新状态（2026-11-09）：16/16 家公司，在招 996 个岗位，追踪技术岗 782 个；累计 P1 146 个、P2 0 个；已排除非技术/G&A 岗位 233 个。年龄类信号 12 月中旬才开始出现（first_seen 累计）。

监视的 16 家公司：Agility Robotics、Figure AI、Tenstorrent、Apptronik、Skild AI、Reflex（Greenhouse）；FieldAI（Lever）；Serval、Physical Intelligence、Infisical、1X、General Compute、Hyperbolic、Dexmate、Hyphenate、Cohere（Ashby）。
