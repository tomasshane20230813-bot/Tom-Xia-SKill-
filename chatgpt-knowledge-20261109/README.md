## 使用习惯
- 新的 HR 书面答复覆盖旧版口径，所有硬性条件记录出处及更新日期。
- 岗位适配评分与 Active 看机会评分独立；未验证不等于不符合。
- 候选人评分必须有证据来源、日期、疑点与后续核实动作。
- 不上传候选人私人邮箱、电话号码、简历全文、客户未公开报价、合同内部条款或任何凭证。
