# 根据本科毕业年合理判断工作起点

Tom 于 2026-11-15 明确要求：本科毕业年已经落在要求范围内时，要结合常见职业路径作合理判断，不能仅因缺少首份工作的逐条记录而把时间门卡为不合格。

## 默认判定

当岗位要求“本科毕业年与首份真实工作均不早于某个年份”时：

- 已有可信资料确认本科毕业年不早于截止年，并且没有发现截止年前的正式工作反证，判为“时间门通过（依据本科毕业年合理推断）”。
- 例如截止年为 2015，本科于 2017 年毕业，档案最早可见正式工作为 2017 年或之后，或者未列首份工作的日期，都按时间门通过；不再为缺首职记录反复阻塞推荐。
- 评分时按时间门通过处理，不因“未逐条证明不存在更早工作”扣时间门分。其他职责、业绩、产品、地点等维度仍按各自证据判断。
- 可以在后续常规沟通中顺带核对完整时间线，但不把这项补问作为进入候选池或出初稿的前置条件。

## 反证与边界

- 明确出现截止年前的真实正式工作时，以反证为准，不用较晚毕业年覆盖已知任职事实。
- 区分正式工作与实习、校园活动、毕业项目；学生实习、社团职务或毕业项目不能直接当作更早的第一份正式工作。零工、兼职等性质不清时结合说明判断，不机械套用。
- 只有硕士、培训或其他后续学历结束年时，不能替代本科学历毕业年。学位层级与学校被遮挡时，不能把可见结束年直接认定为本科毕业年。
- 本科毕业年本身未知或来源冲突时，写明具体缺口，补读有效职业资料；不要编造年份。
- 不以本科毕业年推断年龄、出生年份、性别、族裔或国籍。

## 报告措辞

推荐写法：

> 本科 2017 年毕业；未见 2015 年前正式工作记录。按本科毕业年合理推断，时间门通过，首份真实工作起点未直接核实。

若已查到首职日期，另外写明日期与来源。合理推断只能支持时间门判断，不能写成“已证实首份工作始于某年”，也不能补造不存在的任职记录。

每份初稿采用当轮最新截止年，不把示例中的 2015 固定成所有项目的通用要求。
