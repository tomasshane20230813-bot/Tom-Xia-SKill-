# 客户版推荐报告规范
1. 获取原始CV、指定Word模板、客户最新JD及录音。调用本地WebCodex转写Skill；核对源文件、先抽测再完整转写，中英混合误识别时分段复核。仅使用有明确证据的候选人陈述，不把猎头提问当候选人事实。
2. 使用Gary Ling金山云原Word模板，保留FORESTOWN标题、推荐机构、个人信息、学历、薪酬、到岗信息、三条核心优势及400汉字以内客观评价。客户版只突出优势，不放扣分或缺点；缺失资料不猜测。
3. 原英文CV非联系方式逐句完整翻译中文，保留原文全部职责、技能、项目、日期、量化结果及重复内容。删除用户要求移除的邮箱、电话、链接、地址及推荐人联系方式。
4. 同公司任职合并为一段总起止时间，旗下职位和日期按倒序排列；真实收购承接可合并但不能虚构连续雇佣。把录音确认的项目、职责、客户及成果直接融入对应公司/职位中；禁止另设“电话录音补充”“录音核实亮点”等割裂章节。内部留存证据，客户版不加冗余来源标签。
5. 对岗位相关技术、项目、客户、量化成果在Word中实际使用黄色highlight及bold，不只写亮点标签。准确区分个人与团队业绩、技术边界和项目阶段；不夸张。
6. 原CV有职业照且用户要求时，直接提取原照置于首页右上角，避免遮挡及破坏分页，不生成替代头像。
7. 文件名：候选人姓名--目标企业+推荐职位（方向） -福睿思特推荐报告.docx；存指定CV目录。重新打开检查内容、原文覆盖、真实高亮、照片嵌入、评价字数、联系方式及旧模板残留；实际渲染检查分页后交付。只提供真实可下载文件或经核实的导出链接。无法核实的事实在交付说明中披露。
8. 候选人初筛问题默认中文。公开仓库只保存通用制作规范，不上传真实候选人的简历、照片、录音、联系方式或薪酬。
