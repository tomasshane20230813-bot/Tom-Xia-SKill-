# 姓名像华人，语言给满分

Tom 于 2026-11-15 定下，并要求以后审定人选、给寻访 Agent 下口径时都执行：名字可以侧面判断是华人；这类人的语言项一律给高分，按该维度满分计。

## 怎么判

- 华人身份只看姓名外观，规则见 `chinese-name-by-appearance`：高置信华人姓，或全名是中文拼音组合，即通过。
- 不要求汉字，不要求语言栏写 Mandarin、Chinese、普通话或 Native。
- 通过后，语言/中文工作能力这一项给该评分表里的上限满分。例如该项满分 15，就记 15，不要记 0 或 5。
- 全部按此执行，不要只给其中几个人高分。

## 报告怎么写

- 写：「姓名侧面判定华人。语言项按口径给满分。」
- 语言栏没有原文时，不要编造成「档案写了 Native / bilingual / Full professional」。满分是评分口径，不是伪造语言栏原文。
- 不从姓名推断国籍、公民、PR 或年龄。

## 满分不能代替别的证据

- 语言满分只补语言这一项。
- 没有职责原文，仍然不能单靠语言满分抬到达标线。
- 时间门、地点、旧库查重、LinkedIn URL 各自照旧。

## 不要再这样做

- 不要写「姓名不用于推断语言」。
- 不要因为语言栏空白，把中文能力记 0 分或只给象征性低分。
