# 卡点交出去，其余任务继续做

Tom 于 2026-11-22 定死，长期有效，所有职位、所有 Agent 通用。

## 规则

1. 卡住的只交那一条：登录墙读不到、缺全名、插件 402/限流、需要代调插件等，立刻把 URL 和要补的字段交给 CEO（或 Tom 指定的协助方，如 MAUS 桥接的大总管）。
2. 交完不等：不空等回执，马上接着做队列里下一家公司或下一批人选。回执到了再回填，另存新版。
3. 不准偷懒停工：一家公司做完、一批送审完，都不是停下来的理由。只有整个任务完成，或 Tom 明确叫停，才能停。
4. 如实汇报：没完成就说没完成。写清计入人数、还剩哪些公司或任务、卡在哪里、交给了谁。
5. CEO 同样受约束：派活、巡检、收口时不得下“交完就停”“落盘后停”的指令；收口令只能是“几点前另存最后一版”，到死线前持续推进。
6. 推进不越红线：继续做不等于抬分、编造职责或绕过登录墙。仍遵守 tom-redlines-and-bottomlines。

## 汇报模板

没完成。计入 X/目标。已做：A、B、C。卡点：某人某字段，已交 CEO 代读。现在接着做：D。还剩：E、F。
