# Ongoing Process Format（一行最新进展）

Tom 2026-11-27 立规矩：Ongoing Process 每人只写最新进展一行，历史流水账一律不写。

## 规则

1. 每人一行。格式：`名字：最新进展；下一步动作与时点。`
2. 只写现在是什么状态、在等什么、下一步是什么时候。已成过去的经过（怎么走到这一步、哪天发生了什么、谁说了什么）一律不写。
3. 状态变了，整行替换，不追加。绝不在一行后面续写历史。
4. 薪资只写当前有效的数字（如 offer 薪资 SGD 5,500/月），不写谈判过程。
5. 同一人的多条旧信息合并成一行时，只保留最新那条；旧信息若已过时，直接删掉，不要留“曾”“原先”。
6. 条目按现状增删：人选完结（入职 / 拒绝 / 淘汰）就从 Ongoing 撤掉，不留墓碑。

## 适用范围

- 四处 Ongoing 副本保持逐字一致：猎头空间留底模板（id 9，同时置顶 Headline）、Notion「2026年11月计划」页、Notion 每周五复盘页、Notion 月底复盘页。
- 新复盘页建页时，Ongoing 直接抄最新版条目，不从旧页粘贴历史。
- 与 candidate-progress-sync 配合：人选进展反馈仍同步四处（空间卡、Notion 行、人物档、Ongoing），但 Ongoing 那一条按本规则只写一行最新进展。

## 改写后核验

改完必须读回 Tom 看的页面原文，逐行核对每条都是最新进展一行，无历史段落。
