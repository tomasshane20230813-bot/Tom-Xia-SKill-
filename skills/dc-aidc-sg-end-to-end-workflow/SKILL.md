# 新马数据中心技术支持寻访：端到端流程

Tom 于 2026-11-13 这一轮定下的完整做法。除非他专门改口，以后同类岗位都按这个跑。

## 1. 角色

- 寻访端（PI+）负责找人和初评。
- 大总管负责终审、巡检、裁决是否收口。
- 不要擅自把终审转给 Google Antigravity、Maus 或 Codex。Tom 点名谁审就谁审；他没点名时默认大总管。
- 支线（A2/A3 等）可以协助抓档案，但它们停掉不构成主流程阻塞。

## 2. 时间与早交

- 死线以 Tom 最后一次说的为准，他会中途延后或改分数线。改了就立刻覆盖旧口径。
- 初稿做完立刻送审，不要等到名义截止时间。见 `early-draft-review-backfill`。
- 终审退回后只补被退回造成的缺口，不整批重做。
- 到点没做完就写真实缺口，不许用低分人或旧人凑满 40。

## 3. 初稿落盘

- 每一版初稿都写入 Tom 当天指定的客户目录，不能只放 `/tmp`。
- 未终审、人数不够、不到分数线的版本也要写，Tom 要自己人工审。
- 文件名带实际完成时分，例如 `_20261113_2238`。
- 客户目录只放人选稿；评审意见、退回说明、过程 README 一律不进。见 `client-folder-final-files`。

## 4. 分数纪律

- 分数线取 Tom 最新指令，70 或 65 都可能出现。不要拿旧线覆盖新线。
- 分项合计必须等于总分。写“约 56 分”这种估算给方向可以，但落表一律按分项合计。
- 只认本人项目原文。以下都不能当项目证据：
  - 雇主名气、职称、证书；
  - 档案里某个关键词出现的次数；
  - 第三方摘要、搜索片段、别人写的简介。
- 有一条扣一条：没有本人数据中心或 BMS/DCIM 原文，就不能给到入围线。

## 5. 华人身份门

- 新马档案里姓氏已确认是华人，或姓名含汉字，华人门直接通过。
- 语言栏没有中文不否决，也不要写成双语或 Native。见 `sea-chinese-name-gate`。
- 只有姓氏拿不准时才要求明示中文证据。
- 不推断国籍、公民、PR。没有原文一律写未核实。
- 技术分再高，华人门不过也不计入合格人数。这是红线，不是可调项。

## 6. 岗位画像

按 `dc-aidc-technical-priority` 排序：

| 维度 | 对标 |
| --- | --- |
| 第一优先 | 真实 AI 智算中心／数据中心项目 |
| 核心技术 | DCIM、BMS、关键设施环境监控 |
| 其他技术 | 机房制冷、HVAC、液冷、供配电及 MEP |
| 对接客户 | 数据中心运营／设计团队、Hyperscalers |
| 目标人选 | 数据中心技术售前、BMS/DCIM、应用及工程方案人 |

纯云、纯网安、纯服务器销售、纯商业楼宇暖通、ICT 结构化布线，都不算对口。

## 7. Active

- 单列 0–10，不计入推荐分，也不是否决项。
- 近 30 天公开活动记 7，31–90 天记 6，无记录记 0。见 `linkedin-activity-as-active`。
- Tom 希望一半人 ≥7 时，那是目标不是门槛；没达到如实报数。

## 8. 新人纪律

- 本地硬盘、Google Drive、Notion、历史黑名单命中的人一律排除。
- 同一任务目录里今天已经出现过的名字，也不能当本轮新人计入，标注“旧人复用，不计入”。
- 每个人入册前先查本轮历史，再写进去。
- 四端没有逐条查完，就在报告里写明未完成，不许写“四端 0 碰撞”。

## 9. 巡检与卡点

- 用 10 分钟只读心跳看状态，正常进度不发消息打断。
- 状态以 CLI 实测为准，不信 agent 自报“没有卡点”。
- 立即报警的情况：
  - `status=error` 或 `idle` 且没有新稿；
  - 额度不足、402、403 大面积出现；
  - CAPTCHA 或登录墙挡住主通道；
  - 模型不被账号允许；
  - 临近死线仍无初稿。
- 报警要写清是哪一端、什么错、已停多久、还差多少。

## 10. 终审动作

收到送审后按顺序做：

1. 核文件：页数、可点击 LinkedIn 链接数、分项合计是否等于总分。
2. 逐人看证据类型：本人项目原文，还是雇主/职称/证书/关键词。
3. 逐人看华人门。
4. 查本轮历史，抓旧人复用。
5. 给出三件事：谁降分或剔除、关键人物是否维持、这版能不能作为初稿收口。
6. 回执只发对话，不写客户目录。

## 11. 硬禁止

- 不登录 Tom 的 LinkedIn，不用本机 Chrome。
- 不导出邮箱、电话。
- 不编造 LinkedIn URL，不用姓名猜 slug。
- 不抬分凑人数，不把 0/40 写成已达成。

## 12. 常见翻车

- 把关键词出现次数当项目经验。
- 把雇主名气当本人职责。
- 把旧人重新包装成新人。
- 语言栏空白就当不会中文。
- 四端没查完却说查完。
- 报“完全可用”，下一轮立刻报错。
- 把评审意见写进客户目录。
