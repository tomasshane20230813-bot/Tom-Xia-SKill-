# 审过的人一个都不删，全部存进客户目录

Tom 于 2026-11-22 21:47 重申，作为长期规则，所有任务都按此执行。

## 规则
1. 任何初稿上的人，审过的、没审过的、不合格的、不计入的、重复的、待核的，一条都不能删。
2. 不合格只标注原因，比如“不计入｜第一学历文凭”或“性别待核”，人留在名单里。
3. CEO 或任何协助方代读、代查时发现的人，即使没进下属初稿，也必须写进客户目录。可以写进下属的下一版带时分新稿，或者写进 CEO 终稿的“代读补入”部分。不能只留在 `/tmp` 或对话里。
4. 下属写盘被拒、只在对话里回传全文的初稿，CEO 必须按原文另存进客户目录。
5. 终稿 PDF 必须收录客户目录里所有初稿出现过的每一个人，再加上代读补入的人。逐人打分、写依据，从高到低排序，存回同一个客户目录。
6. 旧稿不覆盖、不删除。每一版都另存为带时分的新文件。
7. 审核意见可以放 `/tmp` 或对话，但人选本身必须进客户目录。

## 自检
- 终稿人数应大于或等于所有初稿和代读回执里不重复的 `/in/` slug 数。少一人就不能交。
- 汇报时写明总人数、计入人数、不计入人数，以及每人不计入的原因。
